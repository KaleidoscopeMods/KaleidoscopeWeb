**森罗物语：酒馆**（英文：**Kaleidoscope Tavern**）是森罗物语模组系列中围绕葡萄种植、果汁压榨、酒桶发酵和鸡尾酒调制构建的酒馆主题模组。玩家可以从野外采回葡萄藤，在不同基质上培育葡萄，再把果汁酿成具有不同品质与效果的酒饮。

本文档对应模组版本 **1.2.0-forge+mc1.20.1**。项目主要作者为==药水棒冰==、==酒石酸菌==。

## 快速流程

1. 在野外树木下寻找并采集[葡萄藤](/wiki/tavern/cultivation/)。
2. 制作藤架，根据下方基质培育需要的葡萄品种。
3. 把葡萄或浆果放入[果盆](/wiki/tavern/pressing/)，反复跳踩并收集一桶果汁。
4. 向打开的[酒桶](/wiki/tavern/brewing/)加入 **4000 mB** 流体，再投入配方原料并关盖发酵。
5. 在酒桶正面的龙头下放置空瓶，取出当前品质的酒饮。
6. 将优质及以上的酒饮投入[雪克杯](/wiki/tavern/mixology/)，掌握摇制时间后倒入空酒杯。

::: tip 游戏内配方查看
模组内置 JEI、REI 与 EMI 的配方分类，也提供 Jade 信息和 Ponder 教程。文档适合了解完整规则，游戏内查看器更适合临场确认材料。
:::
