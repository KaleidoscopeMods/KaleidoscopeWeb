### 醋的效果

醋在普通及以上品质会从失明、挖掘疲劳、速度、跳跃提升和急迫中分别进行 **15% 概率**判定，可能同时获得多个效果。品质越高，持续时间和等级越高；典藏醋会以 15% 概率分别给予对应效果 3 级、100 秒。

## 鸡尾酒配方与效果

<ItemAnimate name="Tavern cocktails" :size="96" />

固定鸡尾酒没有酒桶品质，饮用效果由成品本身决定。

| 鸡尾酒 | 颜色配方 | 效果 |
| --- | --- | --- |
| 绒球葱花园 | 淡紫 + 淡紫 + 淡紫 | 经验汲取 1800秒 |
| 血腥玛丽 | 红 + 红 + 红 | 血腥玛丽 1800秒 |
| 黄铜心脏 | 金 + 金 + 金 | 醇热 300秒 |
| 翡翠 | 绿 + 绿 + 绿 | 长臂 2700秒 |
| 白色佳人 | 白 + 绿 + 黄 | 高跟鞋 3600秒 |
| 绿色蚱蜢 | 绿 + 绿 + 白 | 穿草隐身 900秒 |
| 莫吉托 | 白 + 白 + 绿 | 灵视 1800秒 |
| 深水炸弹 | 蓝 + 淡紫 + 白 | 醇热 300秒 |
| 教父 | 红 + 红 + 金 | 至高点，立即触发 |
| 螺丝起子 | 黄 + 黄 + 金 | 倒立，立即触发 |

| 幽匿特调 | 蓝 + 蓝 + 淡紫 | 尖啸攻击，立即触发 |

**特调鸡尾酒**没有固定效果：它会混合三份原料当前品质对应的效果，并按原料颜色生成杯中颜色。**谜之鸡尾酒**则只给予微醺 180 秒。

## 莫洛托夫鸡尾酒

<ItemAnimate :name="['kaleidoscope_tavern:molotov']" :size="96" />

莫洛托夫鸡尾酒不是普通饮品。长按使用至少 10 tick 后松开即可投掷；命中时会打碎酒瓶，并在中心半径约 3 格内点燃可燃位置，外围额外 2 格存在随距离降低的随机点燃概率。

::: danger
莫洛托夫会真实放置火焰并消耗酒瓶。请勿在木质酒馆、森林或重要建筑附近随意投掷。
:::
