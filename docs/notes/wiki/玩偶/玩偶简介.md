**森罗物语：玩偶**（英文：**Kaleidoscope Doll**）是森罗物语模组系列中的玩偶主题模组，围绕收集、展示与把玩构建。模组内置 **694 种**编号玩偶（`doll_0`～`doll_693`），并支持通过数据包与资源包无限扩展**自定义玩偶**。玩偶既可以作为装饰方块摆放，也可以转化为实体丢出、骑乘甚至放在别的生物头上，还配有玩偶抽奖机、礼品盲盒、电脑和微调工具等一整套收集玩法。

本文档对应模组版本 **1.4.1-forge+mc1.20.1**。项目作者为==ysbbbbbb==（==药水棒冰==）。

## 快速流程

1. 合成[玩偶抽奖机](/wiki/doll/machine/)，用**铁锭、金锭或钻石**代币抽奖。
2. 破坏出品的[礼品盲盒](/wiki/doll/machine/)，拿到第一只玩偶。
3. 把玩偶摆放为装饰方块，右键听它“嘎嘎”叫。
4. 用玩偶 + **黏液球或粘土球**在工作台合成[实体玩偶](/wiki/doll/entity/)，按住 Shift 右键蓄力丢出。
5. 合成[电脑](/wiki/doll/computer/)，放入羊毛换取捐赠者玩偶。
6. 收集全部 **71 种原版玩偶**，挑战[小小收藏家](/wiki/doll/advancements/)进度。

::: tip 游戏内配方查看
模组内置 JEI 与 EMI 的配方查看支持，也提供 Jade 信息提示。文档适合了解完整规则，游戏内查看器更适合临场确认材料。
:::
