电脑用于把**羊毛**兑换成**玩家玩偶**（捐赠者与作者玩偶）或**自定义玩偶**。它也是把方块玩偶转换为实体玩偶的合成配方在 JEI 中的查询入口。

## 合成电脑

<ItemAnimate :name="['kaleidoscope_doll:computer','kaleidoscope_doll:tweaks_tool']" :size="96" />

电脑在工作台中用 6 个铁锭、1 份红石粉与 3 块平滑石合成：

<CraftingTable
  :grid="[
    'minecraft:iron_ingot', 'minecraft:iron_ingot', 'minecraft:iron_ingot',
    'minecraft:iron_ingot', 'minecraft:redstone', 'minecraft:iron_ingot',
    'minecraft:smooth_stone', 'minecraft:smooth_stone', 'minecraft:smooth_stone'
  ]"
  :result="'kaleidoscope_doll:computer'"
/>

电脑方块硬度 1.25、爆炸抗性 4.2，破坏后掉落自身；放置时正对玩家，并支持含水。

## 电脑界面

<ItemAnimate :name="['kaleidoscope_doll:computer']" :size="96" />

右击电脑打开兑换界面，界面包含：

- **输入槽**（左下）：只接受**羊毛**（任意颜色，`#minecraft:wool`），每次放入 1 个即可兑换一次；
- **输出槽**（右下）：显示兑换出的玩偶，最多放置 1 个；
- **玩偶列表**：每页显示 **32 个**玩偶（8×4），支持滚轮与滚动条翻页；
- **搜索框**：位于界面上方，最多输入 32 个字符。搜索会匹配物品 ID、提示文字（如“作者：药水棒冰”“捐赠者：XXX”）以及自定义玩偶的名称与描述。

操作流程：

1. 向输入槽放入 1 个羊毛；
2. 在列表中找到想要的玩偶并点击（也可以在搜索框中按编号搜索，例如 `doll_0`）；
3. 输出槽出现对应玩偶；
4. 取出输出槽中的玩偶，输入槽中的羊毛同时被消耗。

::: warning 兑换前确认材料
点击玩偶按钮时输入槽必须已有羊毛，否则不会产出。关闭界面时，输入槽中剩余的羊毛会自动返还给玩家。
:::

## 可兑换的玩偶

电脑列表包含两类玩偶：

| 类别 | 内容 | 说明 |
| --- | --- | --- |
| 玩家玩偶 | 全部 **623 种**带特殊提示的玩偶 | 8 种作者玩偶 + 615 种捐赠者/贡献者玩偶 |
| 自定义玩偶 | 服务端加载的全部自定义模型 | 兑换时服务端会校验模型 ID 确实存在 |

::: tip 配置影响
当配置项 **EnableSponsoredDoll** 设为 false 时，电脑列表会隐藏捐赠者玩偶，只保留作者玩偶；幻翼附带玩偶与创造模式“捐赠者”页也会同步隐藏。详见[配置与命令](/wiki/doll/config/)。
:::

## 方块玩偶转实体玩偶

<ItemAnimate :name="['kaleidoscope_doll:doll_entity_item','kaleidoscope_doll:doll_4','kaleidoscope_doll:custom_doll']" :size="96" />

在**工作台**中把 1 个方块玩偶与 1 份**黏液球或粘土球**无序摆放（2×2 及以上网格均可），即可得到对应的**实体玩偶物品**：

<CraftingTable
  icon="shapeless"
  :grid="[
    null, null, null,
    null, { ids: ['kaleidoscope_doll:doll_4', 'kaleidoscope_doll:doll_2', 'kaleidoscope_doll:doll_328'], title: '任意玩偶' }, { ids: ['minecraft:slime_ball', 'minecraft:clay_ball'], title: '黏液球 / 粘土球' },
    null, null, null
  ]"
  :result="'kaleidoscope_doll:doll_entity_item'"
/>

- 输入**任意编号玩偶**（或带模型 ID 的自定义玩偶）+ 黏液球/粘土球，产物为对应外观的实体玩偶；
- 该配方为特殊合成（不参与配方书解锁），已接入 JEI：在 JEI 中查看任意玩偶的工作台分类即可看到对应合成。

实体玩偶可以蓄力投掷、放置成实体或骑乘到生物头上，具体玩法见[玩偶实体](/wiki/doll/entity/)。EMI 则默认隐藏实体玩偶条目。

::: warning 与电脑的区别
电脑的羊毛兑换只会产出**方块形态**的玩家玩偶；想要玩家玩偶的实体版，需要先把玩偶与黏液球/粘土球在工作台合成。
:::
