本页列出森罗玩偶的全部配置项与管理命令。配置文件由 Forge 生成于游戏目录 `config/kaleidoscope_doll-common.toml`，所有选项位于 `[doll]` 段。

## 配置项

| 配置键 | 默认值 | 允许范围 | 说明 |
| --- | --- | --- | --- |
| `EnableSponsoredDoll` | `true` | — | 是否启用赞助玩偶。关闭后：创造模式“捐赠者”页改为屏障图标，电脑列表与幻翼携带玩偶剔除捐赠者玩偶（作者玩偶不受影响） |
| `DollCanBeThrown` | `true` | — | 是否允许玩家投掷实体玩偶 |
| `DollAffectedByWater` | `true` | — | 玩偶是否受水流推动（含水中摩擦与上浮） |
| `DollAffectedByGravity` | `true` | — | 玩偶是否受重力影响 |
| `DollThrowParticleEffect` | `true` | — | 投掷玩偶时是否产生粒子轨迹 |
| `DollCanKnockbackEntities` | `true` | — | 飞行的玩偶能否击退其他实体 |
| `DollKnockbackForce` | `1.0` | `0.0`～`10.0` | 玩偶击退强度倍率，数值越大击退越强 |
| `DollCanMountEntities` | `true` | — | 是否允许把玩偶放置在其他实体上（骑乘） |
| `EnablePhantomDollSpawn` | `true` | — | 是否启用幻翼附带玩偶生成 |
| `PhantomDollSpawnChance` | `0.03` | `0.0`～`1.0` | 幻翼附带玩偶的生成概率（3%） |
| `PhantomDollExistTicks` | `3600` | `-1`～`2147483647` | 幻翼携带的玩偶脱离幻翼后存活的时间（tick，默认 3 分钟）。**设为 0 或负数时玩偶永不消失** |

::: tip 配置文件是通用配置
以上全部为 COMMON 配置，客户端与服务端读取同一份文件。其中 `EnableSponsoredDoll` 等选项在客户端侧也会影响创造物品栏与电脑列表的显示，服务器与整合包请保持两侧配置一致。
:::

::: warning 关于 PhantomDollExistTicks
英文注释写“设为 0 关闭消失”、中文注释写“设为 -1 不消失”，而源码实际以“大于 0 才计时”判断。结论：**0 与负数效果相同，都是永不消失**。
:::

## 命令

模组只注册了一条管理命令：

```
/kaleidoscope_doll reload
```

- 需要**权限等级 2**（管理员）；
- 作用：重新扫描服务端全部自定义玩偶来源（配置目录、zip、数据包），并同步给所有在线玩家；
- 成功时聊天栏显示“**自定义模型重载成功！**”。

玩家加入服务器时，模型列表会自动同步，因此通常只有修改了自定义玩偶文件后才需要手动执行 reload。自定义玩偶的目录结构见[自定义玩偶](/wiki/doll/custom/)。
