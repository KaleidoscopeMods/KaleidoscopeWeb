森罗玩偶支持通过**配置文件目录**或**数据包、资源包**添加自定义玩偶，数量没有上限。自定义玩偶使用基岩版新格式几何模型，可以出现在创造模式、电脑兑换列表与实体玩偶物品栏中。

## 模型要求

- 使用**基岩版新版（1.12+）几何模型 JSON**，顶层包含 `"minecraft:geometry"` 数组；
- 模型的唯一 ID 取自 `geometry[0]` 的 `description.identifier`；
- **旧版（Legacy）格式不受支持**，加载时会报错并跳过；
- 模型引用贴图时按“贴图文件名（不含扩展名）与模型 ID 一致”的规则查找。

模组内置了默认模型（`default_custom_doll`）：当模型或贴图缺失时，会回退到默认模型与默认贴图，最后才是紫黑缺失纹理。

## 目录结构

### 配置文件目录

把文件放入 `.minecraft/config/kaleidoscope_doll/custom/`（服务端与客户端各自读取）：

```
custom/
├── models/            # 基岩版几何模型 *.json（identifier 即模型 ID）
├── lang/
│   ├── zh_cn.json     # { "模型ID": "描述文本" }
│   └── en_us.json
└── textures/          # *.png，文件名（不含扩展名）必须等于模型 ID
```

也可以把整个目录结构打包成 **zip** 直接放入 `custom/`，兼容“zip 根目录直接是 models/lang/textures”与“带一个顶层文件夹”两种结构。

### 数据包（服务端注册）

在任意命名空间的 `data/<namespace>/custom_dolls.json` 中写入模型 ID 的字符串数组，例如：

```json
["geometry.example_doll", "geometry.another_doll"]
```

服务端只读取 ID 列表用于注册与校验，几何体与贴图仍需通过资源包或配置目录提供。

### 资源包（客户端渲染）

资源包中对应目录为 `assets/<namespace>/custom_dolls/`：

```
assets/<namespace>/custom_dolls/
├── models/*.json
├── lang/zh_cn.json
└── textures/*.png
```

## 语言与贴图规则

- **语言文件**是“模型 ID → 描述文本”的映射；文本中的 `\n` 会在物品提示中换行显示。查找顺序为当前语言 → `en_us` → 键名本身。
- **贴图**：文件名（不含扩展名）必须与模型 identifier 一致。模组会把贴图注册为动态纹理（`kaleidoscope_doll:custom/<md5>`），因此不必担心与其它资源重名。
- 没有模型 ID 的自定义玩偶物品会显示“**未知玩偶**”。

## 加载与重载

| 时机 | 行为 |
| --- | --- |
| 游戏启动 / 资源包重载 | 客户端读取配置目录与资源包，服务端读取配置目录与数据包 |
| 玩家进入服务器 | 服务端向该玩家同步可用的模型 ID 列表 |
| 执行 `/kaleidoscope_doll reload` | 服务端重新扫描全部来源，并向所有在线玩家广播，同时重建创造物品栏 |

更多命令细节见[配置与命令](/wiki/doll/config/)。

## 与其它系统的联动

- **创造物品栏**：“森罗物语：自定义玩偶”页会为每个已加载的模型生成一个物品；实体版则出现在“森罗物语：实体玩偶”页；
- **电脑**：自定义玩偶出现在电脑列表中，可以用羊毛兑换；服务端会校验模型 ID 真实存在；
- **JEI**：自定义玩偶与黏液球/粘土球的合成会按模型 ID 单独列出，实体玩偶也通过子类型区分外观；
- **Jade**：自定义玩偶的方块与实体会标注“自定义”。

::: tip 内置示例
模组自带了 4 个自定义玩偶示例：`geometry.little_winefox`（小酒狐狐玩偶）、`geometry.normal_winefox`（酒狐狐玩偶）、`geometry.zhiban`（纸板玩偶）、`geometry.hailuo`（海螺玩偶），可参考它们的文件组织方式。
:::
