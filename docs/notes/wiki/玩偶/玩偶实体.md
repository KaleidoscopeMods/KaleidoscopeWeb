本页介绍**实体玩偶**的获取与把玩方式：把方块玩偶转换为实体、蓄力投掷、物理效果、交互、微调工具、骑乘生物以及幻翼带来的惊喜。

## 获取实体玩偶

<ItemAnimate :name="['kaleidoscope_doll:doll_entity_item']" :size="96" />

实体玩偶物品有两个来源：

1. **工作台合成**：任意方块玩偶 + 黏液球或粘土球（详见[电脑：方块玩偶转实体玩偶](/wiki/doll/computer/#方块玩偶转实体玩偶)）；
2. **创造模式**：在“森罗物语：实体玩偶”物品栏页直接取出，其中包含全部编号玩偶与已加载自定义玩偶的实体版。

实体玩偶物品会把玩偶实体的全部状态（外观、缩放、位移、手持物品等）记录在自身数据中，因此重新放置或投掷时能保留上次调整的结果。

## 放置

手持实体玩偶**右击方块表面**，会在点击面外侧生成一只实体玩偶；右击**可骑乘的实体**则会把玩偶放到该生物头上（见下文[骑乘生物](#骑乘生物)）。

## 蓄力投掷

1. 手持实体玩偶，**按住 Shift 并长按右键**开始蓄力（玩家会做出拉弓动作）；
2. 蓄力至少 **5 tick** 后松开；
3. 玩偶沿视线方向飞出，初速度随蓄力时间在 **0.1～3** 之间提升，并伴随雪球投掷音效。

投掷的玩偶在飞行中会不断旋转，默认还会拖出**荧石色粒子轨迹**（可由配置 `DollThrowParticleEffect` 关闭）。生存模式下每次投掷消耗 1 个实体玩偶物品。

::: warning
蓄力不足 5 tick 就松开不会投出玩偶。在水中、细雪中等同样可以蓄力，但飞行中的玩偶会受到流体影响。
:::

## 物理效果

实体玩偶默认参与重力、流体与碰撞：

- **重力**：每 tick 获得 0.04 的下落加速度；
- **流体**：水中摩擦系数 0.95、熔岩 0.9，并受到轻微上浮；水流会推动玩偶；
- **弹跳**：落地时垂直速度变为 **-0.5 倍**，即弹起约一半高度；弹跳瞬间伴随挤压动画；
- **空中旋转**：飞行速度较快时会随机“托马斯大回旋”；
- **击退**：飞行的玩偶碰撞生物时，若速度不低于 0.25，会击退对方并冒出暴击粒子。击退不造成伤害，强度由速度、玩偶尺寸与配置 `DollKnockbackForce` 决定；连续命中 5 次后会短暂停止判定。

以上大部分行为都可以在[配置与命令](/wiki/doll/config/)中开关。

## 交互

| 操作 | 效果 |
| --- | --- |
| 空手右击 | 玩偶播放“鸭子玩具”音效并冒出音符粒子 |
| 潜行 + 手持物品右击 | 把手中物品拆出 1 份交给玩偶**手持展示** |
| 潜行 + 空手右击 | 取回玩偶手中的物品 |
| 手持微调工具右击 | 打开微调工具界面 |

连续交互有 500 毫秒冷却。只有**玩家直接攻击**能破坏实体玩偶：玩偶被破坏时掉落自身（保留全部调整数据，可在创造模式用中键直接复制），同时掉落它手持的物品。

::: tip 游戏规则
玩偶的掉落遵循 `doEntityDrops` 游戏规则；关闭该规则后，破坏玩偶不会返还实体玩偶物品。
:::

## 微调工具

<ItemAnimate :name="['kaleidoscope_doll:tweaks_tool']" :size="96" />

**指指点点**（微调工具）最大堆叠 1，用 2 个羊毛与 1 根木棍合成：

    null, 'minecraft:stick', null
  ]"
  :result="'kaleidoscope_doll:tweaks_tool'"
/>

手持它右击实体玩偶，会打开调整界面，可以分别设置：

- **整体**：缩放 X/Y/Z、位移 X/Y/Z、旋转 X/Y；
- **手持物品**：缩放 X/Y/Z、位移 X/Y/Z、旋转 X/Y/Z。

每点击一次“+”或“-”按钮，缩放与位移变化 **0.1**，旋转变化 **1°**；**按住 Shift 点击**变化 10 倍，**按住 Ctrl 点击**变化 0.1 倍。界面中央的**重置**按钮会恢复缩放 1 倍、位移归零，并让玩偶转向玩家。

::: warning 数值上限
服务端会强制把整体缩放钳制在 **0.1～10**、整体位移钳制在 **-5～5**、旋转 X 钳制在 **-90°～90°** 之间。整合包即使通过其他方式修改 NBT，也不会超过这一范围。
:::

## 骑乘生物

当配置 `DollCanMountEntities` 开启（默认开启）时，手持实体玩偶右击任意**可骑乘生物**，玩偶会骑到它头上。被骑乘的生物包括马、猪、幻翼等原版坐骑与大部分模组生物。

每只玩偶都算作一层乘客：从目标生物向上数（包含目标自身），**最多 5 层**，超过后无法继续叠加。骑在幻翼上时，玩偶会跟随幻翼俯仰；幻翼死亡后玩偶坠落地面，并从此刻开始计时（见下节）。

## 幻翼送货

当配置 `EnablePhantomDollSpawn` 开启时，每只**幻翼**加入世界有 **3%** 概率（`PhantomDollSpawnChance`）携带一只随机外观的玩偶一起生成。玩偶会骑在幻翼背上，幻翼被击杀或玩偶被打落后：

- 玩偶从脱离幻翼时开始计时，默认 **3600 tick（3 分钟）**后冒出烟雾粒子并消失；
- 该时长由配置 `PhantomDollExistTicks` 决定，设为 **0 或负数可永久保留**。

::: tip
幻翼携带的玩偶同样遵守赞助玩偶过滤：`EnableSponsoredDoll` 关闭时，只会携带作者玩偶与原版玩偶。
:::

## 常见问题

| 现象 | 常见原因与处理方式 |
| --- | --- |
| 长按右键没有开始蓄力 | 确认配置 `DollCanBeThrown` 开启，且处于潜行状态。 |
| 松开后没有丢出玩偶 | 蓄力不足 5 tick；请按住更久再松开。 |
| 玩偶在水中漂走 | `DollAffectedByWater` 开启时玩偶会受水流推动，属正常现象，可在配置中关闭。 |
| 玩偶飞过却不击退生物 | 击退需要速度不低于 0.25，且 `DollCanKnockbackEntities` 开启；连续命中 5 次后需要等待约 1 秒。 |
| 无法把玩偶放到生物头上 | 目标必须是可骑乘生物，且骑乘链未满 5 层；检查 `DollCanMountEntities`。 |
| 幻翼掉落的玩偶突然消失 | 幻翼玩偶默认只保留 3 分钟（`PhantomDollExistTicks`），把配置改为 0 或负数可永久保留。 |
| 微调工具数值无法超过上限 | 服务端会钳制缩放（0.1～10）与位移（±5），无法超出。 |
