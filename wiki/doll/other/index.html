玩偶杂项

2026-07-21

本页介绍森罗玩偶中不属于收集、抽奖或实体玩法的内容：创造模式物品栏、Curios 联动、JEI/EMI/Jade 查看器支持、音效，以及模组的基本信息。

创造模式物品栏

模组注册了 5 个创造物品栏页：

页签图标内容
森罗物语：原版玩偶doll_52玩偶抽奖机、电脑、微调工具、三种礼品盲盒，以及全部 71 种原版玩偶
森罗物语：捐赠者电脑全部捐赠者玩偶；EnableSponsoredDoll 关闭时仅显示屏障
森罗物语：实体玩偶doll_5全部编号玩偶与自定义玩偶的实体版物品
森罗物语：作者/贡献者doll_08 种作者玩偶
森罗物语：自定义玩偶默认自定义玩偶无 NBT 的默认自定义玩偶 + 每个已加载模型各一个

Curios 联动

玩偶 doll_4

安装 Curios API 后，玩偶可以穿戴在玩家的头部槽位上：

  • 模组注册了头部槽位（1 格，允许装饰层），并校验 kaleidoscope_doll:doll_item 谓词；
  • 所有编号玩偶（DollItem）与自定义玩偶都符合谓词，可以放入头部槽；
  • 穿戴的玩偶会以原版头颅的渲染方式显示在玩家头上，支持 default 与 slim 两种皮肤模型。

即使没有 Curios，玩偶物品自身的装备槽位也是头部（EquipmentSlot.HEAD），可以直接放入原版头盔栏。

JEI / EMI / Jade

  • JEI：为实体玩偶注册了子类型解释器，不同外观的实体玩偶在 JEI 中被视为不同物品；“方块玩偶 → 实体玩偶”的合成会在工作台分类中为每个玩偶单独列出。
  • EMI：默认隐藏捐赠者玩偶与全部实体玩偶条目，并在黄色礼品盲盒后追加 doll_0 作为展示。
  • Jade：看向玩偶方块或玩偶实体时，会以青色文字显示其类别（原版、自定义、作者、捐赠者等），可在 Jade 配置中分别开关“方块玩偶”与“实体玩偶”两个模块。

音效

模组只注册了一个音效事件：

事件字幕触发
block.duck_toy声音：鸭子玩具右击玩偶方块或实体玩偶；音调随机在 0.75～1.25 之间，固定传播 16 格
